# CCNA-Notes-Labs# CCNA Hands-on Labs Project

## Overview
This repository represents a complete CCNA practical learning journey, covering networking fundamentals to advanced enterprise-level network design using Cisco Packet Tracer.

The project was built step-by-step to simulate real-world networking environments and improve practical skills in configuration, troubleshooting, and network design.

---

## Project Structure

### 01 - Network Fundamentals
Covers basic networking concepts:
- OSI & TCP/IP Models
- Networking devices (Router, Switch, etc.)
- Cabling types
- Basic subnetting practice

---

### 02 - IP Connectivity
Focuses on core networking operations:
- VLANs and Inter-VLAN Routing
- Static Routing
- OSPF Dynamic Routing
- DHCP Configuration
- NAT (PAT & Basic Internet Access)
- Final Integrated Enterprise Lab

---

### 03 - IP Services
Provides essential network services:
- DNS (Domain Name System)
- NTP (Time Synchronization)
- Syslog Monitoring
- SSH & Telnet Remote Access
- Basic Device Services Configuration

---

### 04 - Security
Focuses on network protection:
- Port Security on Switches
- ACL (Access Control Lists)
- Device Hardening (Passwords, Console, VTY)
- Secure Remote Access using SSH

---

### 05 - Automation & Monitoring
Advanced operations and troubleshooting:
- Network Monitoring (Syslog/NTP)
- Troubleshooting Labs
- Network Diagnostics
- Final Enterprise Integration Scenario

---

## Key Skills Gained
- Cisco Router & Switch Configuration
- IP Addressing & Subnetting
- VLAN & Inter-VLAN Routing
- Static & Dynamic Routing (OSPF)
- DHCP & NAT Implementation
- Network Security (ACL, Port Security, SSH)
- Network Monitoring & Troubleshooting

---

## Tools Used
- Cisco Packet Tracer
- Cisco IOS CLI
- Git & GitHub for version control

---

## Objective
The goal of this project is to build strong hands-on networking skills aligned with CCNA certification and real-world network engineering environments.

---

## Final Outcome
By completing this project, a full enterprise-style network was designed, configured, and tested successfully, simulating real production network behavior.
