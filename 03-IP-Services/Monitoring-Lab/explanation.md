# Day 19 - Network Monitoring & Logging Lab

## Overview
This lab demonstrates how to monitor network devices using Syslog and synchronize time using NTP.

---

## Objective
- Enable logging on router
- Send logs to external server
- Synchronize time using NTP
- Monitor network events

---

## Topology
PC → Switch → Router → Server

---

## Syslog Concept
Syslog allows network devices to send log messages to a central server for monitoring and troubleshooting.

---

## NTP Concept
NTP (Network Time Protocol) synchronizes time across network devices.

---

## Configuration

- Logging enabled on router
- Logs sent to Syslog server
- Logging level set to informational
- NTP configured for time sync

---

## Verification

- show logging
- show ntp status
- show clock

---

## Result
Logs are successfully sent to server and time is synchronized.

---

## Key Concepts

- Centralized logging
- Event monitoring
- Time synchronization
- Troubleshooting support

---

## Conclusion
Monitoring and logging are essential for maintaining network stability and troubleshooting issues effectively.
