# Day 18 - Troubleshooting Lab

## Overview
This lab focuses on troubleshooting network issues by identifying and fixing configuration errors.

---

## Objective
- Identify common network issues
- Practice troubleshooting commands
- Fix connectivity problems

---

## Issues Found
- Interface shutdown on Router1
- Incorrect static route on Router2

---

## Troubleshooting Steps
- Checked interface status
- Verified routing tables
- Tested connectivity step by step

---

## Result
Network connectivity restored successfully after fixing errors.

---

## Key Concepts
- Always check interfaces first
- Verify routing paths
- Test hop-by-hop
- Use show commands effectively

---

## Conclusion
Troubleshooting is a critical skill in networking and requires logical thinking and systematic checking.
