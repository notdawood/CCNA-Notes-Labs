# Day 17 - Final Integration Lab

## Overview
This lab combines multiple networking technologies into one real-world scenario.

---

## Technologies Used
- VLAN
- Inter-VLAN Routing
- DHCP
- NAT (PAT)
- ACL

---

## Objective
- Create multiple VLANs
- Enable communication between VLANs
- Assign IPs automatically using DHCP
- Allow internet access using NAT
- Apply ACL for security

---

## How It Works

- VLANs separate network logically
- Router performs routing between VLANs
- DHCP assigns IPs automatically
- NAT allows access to external network
- ACL restricts specific device access

---

## Result

- Devices communicate across VLANs
- Internet simulation works
- Security policy applied successfully
