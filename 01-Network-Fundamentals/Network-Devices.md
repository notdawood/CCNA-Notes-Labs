# Network Devices

## 1. Router
- Connects different networks
- Works on Layer 3 (IP)
- Uses routing tables

## 2. Switch
- Connects devices in the same network
- Works on Layer 2 (MAC)
- Uses MAC address table

## 3. Hub
- Broadcasts to all devices
- No intelligence (Layer 1)

## 4. Access Point
- Provides wireless connectivity (WiFi)

---

# Routing Basics

Routing is the process of sending data between different networks.

## Example:
- PC1 → Router → Internet → Server

# VLAN (Intro)

## What is VLAN?
Virtual LAN allows you to divide a switch into multiple logical networks.

## Why use VLAN?
- Security
- Organization
- Reduce broadcast traffic

## Example:
- VLAN 10 → HR
- VLAN 20 → IT
