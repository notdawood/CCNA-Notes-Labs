# TCP/IP Model

## What is TCP/IP Model?
TCP/IP is a communication model used for networking and the internet.

## Layers of TCP/IP Model

1. Application Layer
2. Transport Layer
3. Internet Layer
4. Network Access Layer

---

## TCP/IP vs OSI

| TCP/IP | OSI |
|------|-----|
| 4 Layers | 7 Layers |
| Practical | Theoretical |

---

## Common Ports

- HTTP → 80
- HTTPS → 443
- SSH → 22
- FTP → 21
- DNS → 53

## Notes

- TCP is connection-oriented
- IP handles addressing and routing
