# OSI Model

## What is OSI Model?
The OSI (Open Systems Interconnection) model is a conceptual framework used to understand how networking systems communicate.

It consists of 7 layers.

## OSI Layers

1. Physical
2. Data Link
3. Network
4. Transport
5. Session
6. Presentation
7. Application

## Easy Way to Remember

## My Notes
- Each layer has a specific function
- Data moves from top to bottom when sending
- Troubleshooting often depends on layer

## Example
If internet is not working:
- Check cable → Physical Layer
- Check IP → Network Layer
