# Subnetting

## What is Subnetting?
Subnetting is the process of dividing a network into smaller sub-networks.

## Why we use it?
- Better network performance
- Improved security
- Efficient IP address usage

## Example

IP: 192.168.1.0/24

Subnet mask: 255.255.255.0

This gives:
- 256 total IPs
- 254 usable hosts

## My Notes
- Always remember: 2^n = number of hosts
- Subnetting depends on borrowed bits
