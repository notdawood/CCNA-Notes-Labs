# Day 20 - Final Enterprise Network Project

## Overview
This is a full enterprise-level network simulation combining switching, routing, DHCP, NAT, and VLANs.

---

## Technologies Used
- VLANs (Segmentation)
- Inter-VLAN Routing
- DHCP (Auto IP assignment)
- NAT (Internet access)
- Static Routing
- Switching

---

## Topology
Multiple VLANs connected to a central router with WAN connectivity to ISP.

---

## How It Works

1. VLANs separate departments
2. Router performs inter-VLAN routing
3. DHCP assigns IPs automatically
4. NAT allows internet access
5. ISP router simulates external network

---

## Result

- All PCs communicate internally
- Inter-VLAN communication works
- Internet access simulated via NAT

---

## Conclusion
This project simulates a real enterprise network and combines all CCNA concepts into one working system.
